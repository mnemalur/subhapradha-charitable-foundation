## [0.1.0] - 2024-01-13

### Added
- Initial project setup with Next.js 14.2.5 and TypeScript
- Sanity CMS v4 integration with embedded studio
- Professional charitable organization branding
- Organization name: "Subhapradha Charitable Organization" (SCO)
- Charity-focused logo with heart symbol and helping hands
- Responsive header with navigation and mobile menu
- Hero section with impact statistics and call-to-action
- Programs section showcasing four key initiatives:
  - Education for All
  - Healthcare Access
  - Women Empowerment
  - Environmental Conservation
- Call-to-action section for donations with transparency promise
- Footer with social links and contact information
- Green and blue color scheme representing hope and trust
- Compassionate, service-oriented messaging throughout
- Mobile-responsive design with modern UI/UX

### Technical Features
- Next.js App Router implementation
- Tailwind CSS for styling
- TypeScript for type safety
- ESLint for code quality
- Sanity Studio embedded at `/studio` route
- Environment variables configuration
- CORS origins setup for Sanity

### Branding & Identity
- SCO acronym established
- Professional charity organization tone
- Trust-building elements and transparency messaging
- Impact statistics display
- Service-oriented language
