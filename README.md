# Subhapradha Charitable Organization (SCO)

A professional website for the Subhapradha Charitable Organization, built with Next.js, TypeScript, and Sanity CMS.

## 🚀 Live Demo

The website is deployed and available for client review.

## 🛠️ Tech Stack

- **Framework:** Next.js 14.2.5 with App Router
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **CMS:** Sanity v4 with embedded studio
- **Deployment:** Vercel

## 📋 Features

- Professional charitable organization branding
- Responsive design with mobile navigation
- Hero section with impact statistics
- Programs showcase with four key initiatives
- Call-to-action sections for donations
- Sanity CMS integration for content management

## 🏗️ Project Structure

```
src/
├── app/                 # Next.js App Router pages
├── components/          # React components
└── sanity/             # Sanity CMS configuration
```

## 🚀 Getting Started

1. Clone the repository
2. Install dependencies: `npm install`
3. Set up environment variables
4. Run development server: `npm run dev`
